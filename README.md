# Донские озёра

Основной публичный адрес — https://donozera.ru. Сайт базы отдыха на Astro 7. Публичная часть — статические страницы и медиа в Nginx. Отдельная админка работает на Node.js и открывается только через Tailscale Serve.

## Разработка

Нужен Node.js 24 LTS.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4321 --ignore-lock
npm run build
npm run check:site
npm run test:unit
npx playwright install chromium
npm run test:e2e
```

`npm run admin:dev` запускает локальную админку на `127.0.0.1:8787`. Если порт занят: `ADMIN_PORT=8789 npm run admin:dev`. Локальный черновик хранится в `.admin-data/`, исключённой из Git. Кнопка публикации рассчитана на Linux-сервер с установленной структурой каталогов, а локально проверяется через интеграционные тесты.

## Редактирование владельцем

1. Подключитесь к своей сети Tailscale и откройте https://donozera.taila31b54.ts.net/.
2. Измените цены, описания, телефон или время работы.
3. Нажмите **Сохранить черновик**. Публичный сайт пока не изменится.
4. Нажмите **Опубликовать изменения** и дождитесь сообщения об успехе.
5. Обновите публичную страницу. Цены на карте и в карточках будут одинаковыми.

Пустые описания, неверные телефоны, некорректные часы работы и отрицательные цены отклоняются. Если черновик изменён в другой вкладке, сохранение остановится с понятным сообщением, чтобы не затереть чужие правки.

## Основные файлы

- `src/content/managed.json` — исходные цены, описания и контакты; используются главной страницей и картой.
- `admin/schema.mjs` — редактируемые поля и серверная проверка данных.
- `admin/` — приватный интерфейс, API черновиков и публикации. Не входит в `dist`.
- `src/content/places.ts` и `map-geometry.ts` — объекты и геометрия карты.
- `src/content/galleries.ts` — привязка фото и видео к объектам.
- `src/lib/site.ts` — галереи, меню, выбор объектов и анимация появления разделов.
- `deploy/publish.mjs` — проверка новой сборки и атомарное переключение сайта.
- `deploy/server/` — актуальные Nginx, systemd, получение деплоя и откат.
- `.github/workflows/site.yml` — проверки и деплой GitHub Actions.
- `deploy/DEPLOY.md` — установка, доступы, резервное копирование и восстановление.

## Проверки

Автоматические проверки охватывают данные и медиа сборки, все объекты карты, галереи с фото и видео, мобильное меню, тему и её сохранение, reduced motion, клавиатуру и страницу 404. Проверки админки охватывают черновики, CSRF, конкурирующие вкладки и валидацию; интеграционный тест публикации проверяет сохранение цен при обновлении кода и неизменность работающего сайта при ошибке сборки.

## Материалы владельца

Используются настоящие фотографии из `public/images/` и видео из `public/videos/`. Объекты без собственных фото показываются с описанием, без пустого блока изображения. Для платформы бани № 1 отдельное фото пока не предоставлено. Цены и вместимость бань пока предлагается уточнять по телефону; их можно вписать в админке после подтверждения владельцем.

`/map-review/` — локальный редактор расположения объектов. Его изменения сохраняются в localStorage и не публикуются автоматически. Страница удаляется из публичных релизов и дополнительно закрыта Nginx.

Каталоги `deploy/edge`, `deploy/nginx`, прежний Compose и локальный `scripts/prepare-deploy.mjs` относятся к старому, отложенному варианту размещения. Текущий деплой их не использует.
